# Model Overview

## Purpose

The model estimates the financial potential of Project X over a 36-month period.

## Core Assumptions

- Starting active users: 2,500 in the base scenario
- Commission from successful rental deals: 3–5% range, with 4% used as base average
- Premium subscription: 399 RUB per month in the base scenario
- Promoted listings: 199 RUB in the base scenario
- Paid listings are introduced after the product reaches stronger user traction

## Revenue Streams

1. Transaction commission
2. Premium subscription
3. Advertising
4. Partnerships
5. Promoted listings
6. Paid listings

## Main Outputs

- Revenue forecast
- User growth forecast
- EBITDA
- Net profit
- Cash flow
- NPV
- IRR framework
- Sensitivity analysis

## Use Case

This model can be used as a portfolio project for Junior Financial Analyst, Business Analyst or Banking Analyst roles.
