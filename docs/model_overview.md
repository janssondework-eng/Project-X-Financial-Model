# Model Overview

## Purpose

The model estimates the financial potential of Project X over a 36-month period.

Project X is modeled as an early-stage marketplace / digital platform with multiple monetization streams and scenario-driven assumptions.

## Model Architecture

| Area | Description |
|---|---|
| Inputs | scenario selector, active users, growth, churn, conversion, pricing, CAC and cost assumptions |
| Operating model | monthly forecast of users, revenue streams and costs |
| Summary outputs | annual revenue, EBITDA, cash flow and active users |
| Unit economics | ARPU, CAC, LTV, LTV/CAC and payback period |
| Valuation | NPV, IRR and revenue multiple valuation |
| Sensitivity | Year 1 revenue sensitivity to deal conversion and commission |
| Dashboard | high-level visual summary |

## Core Assumptions

- Starting active users: 2,500 in the base scenario
- Commission from successful rental deals: 3-5% range, with 4% used as base average
- Premium subscription: 399 RUB per month in the base scenario
- Promoted listings: 199 RUB in the base scenario
- Paid listings are introduced after stronger marketplace traction
- Discount rate: 18% in the base case
- Forecast period: January 2026 to December 2028

## Revenue Streams

1. Transaction commission
2. Premium subscription
3. Advertising
4. Partnerships
5. Promoted listings
6. Paid listings

## Main Outputs

- Revenue forecast
- User growth forecast
- EBITDA
- Net profit
- Free cash flow
- NPV
- IRR
- Implied valuation
- LTV/CAC
- Sensitivity analysis

## Use Case

This model can be used as a portfolio project for Junior Financial Analyst, Business Analyst, FP&A Analyst or Banking Analyst roles.

It demonstrates the ability to structure a model, define assumptions, connect operating drivers to financial outputs, and present a startup investment case.
