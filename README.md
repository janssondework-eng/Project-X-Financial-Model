# Project X Financial Model

## Overview

This repository contains a portfolio-grade financial model for **Project X**, a student housing and roommate matching platform.

The model is built as a 36-month startup financial forecast and includes revenue streams, user growth, unit economics, P&L, cash flow, valuation and sensitivity analysis.

## Business Model

Project X monetization includes:

- Transaction commission from successful rental deals
- Premium subscription
- Advertising revenue
- Partnership revenue
- Promoted listings
- Paid listings after the platform reaches critical mass

## Model Structure

The Excel model includes:

- README / model description
- Assumptions
- User model
- Revenue model
- Unit economics
- P&L
- Cash flow
- Annual forecast
- Valuation
- Sensitivity analysis
- Dashboard
- GitHub notes

## Key Features

- 36-month forecast
- Conservative / Base / Optimistic scenarios
- Scenario selector
- CAC, ARPU, LTV and LTV/CAC calculations
- Break-even logic

- Sensitivity analysis
- Dashboard with charts
